# Security

zERC20 holds its users' funds, so a vulnerability is reported in private, and stays private until a fix is out.

**Report it at [Security → Report a vulnerability](https://github.com/zerc20io/zerc20/security/advisories/new)** in
this repository, or by mail to **[security@zerc20.io](mailto:security@zerc20.io)**. Either way the report reaches the
maintainers alone.

What a report covers:

- the contracts (`contracts/`) and the circuits (`zkp/`);
- the nodes and their enclaves (`backend/`), and the storage canister (`storage/`);
- the wallet SDK (`wallet/`);
- the networks zERC20 has deployed, which `contracts/deployments/` records.

It helps to say what is affected, how to reproduce it, and what it lets someone do.

This repository takes no issues and no pull requests.
